# 语言增强

Inkraft会通过提供外部函数的方式增强Ink语言的功能。



## 数据结构

Inkraft使用Json字符串模拟变长数组（Array）和字典（Map）数据结构，形如`["element1", false, 12]`和`{"key1": "value1", "key2": 2.5}`。

字符串是不可变的，调用函数修改会返回新的字符串，因此需要将返回值重新赋给原变量。

由于Ink语言本身支持的数据类型有限，且范围远小于Json，因此引擎需要对Json字符串进行规范化（Normalize）：
- `null`会转换为`false`，Map中一个条目值为`null`等价于值为`false`；
- Json的Number类型会转换为Ink语言中的Int32和Float32，超出数据范围的部分会被丢弃；
- 读取嵌套的Json容器的时候，内层容器会被递归规范化，再转为Json字符串，例如`[[1.0]]`会被规范化为`["[1.0]"]`；
- Inkraft以Gson的严格Json格式处理Json字符串，
  - 不支持注释、尾部逗号等语法；
  - 函数调用产生的Json字符串不包含空白；
  - 严格Json格式没有`NaN`/`Infinity`字面量，由Ink语言运算产生的特殊Float值会按Ink语言的数据转换规则规范化；
- 所有转换均为静默发生，不产生日志记录。

| 函数定义                          | 函数说明                  | 返回值说明                           |
|-------------------------------|-----------------------|---------------------------------|
| createArray()                 | 创建空数组。                | string，`[]`。                    |
| isArray(str)                  | 检验给定字符串是否为有效数组。       | bool。                           |
| arraySize(array)              | 获取数组长度。               | int；数组无效时返回-1。                  |
| arraySet(array, index, value) | 替换指定下标对应的元素。          | string，数组；数组字符串无效时返回false。      |
| arrayGet(array, index)        | 获取指定下标对应的元素。          | 元素值；数组字符串无效或下标越界时返回false。       |
| arrayAdd(array, value)        | 在末尾添加值。               | string，数组；数组字符串无效时返回false。      |
| arrayRemove(array, index)     | 删除指定下标对应的元素，后续元素向前移动。 | string，数组；数组字符串无效或下标无效时返回false。 |
| arrayContains(array, element) | 检查数组是否给定元素。           | bool；数组字符串无效时返回false。           |

Map的Key只能是字符串类型。

| 函数定义                    | 函数说明             | 返回值说明                                    |
|-------------------------|------------------|------------------------------------------|
| createMap()             | 创建空Map。          | string，`{}`。                             |
| isMap(str)              | 检验给定字符串是否为有效Map。 | bool。                                    |
| mapSize(map)            | 获取Map的key数量。     | int；Map字符串无效时返回-1。                       |
| mapSet(map, key, value) | 创建或覆盖Key。        | string，Map；Map字符串无效时返回false。             |
| mapGet(map, key)        | 获取Key对应的值。       | 给定Key对应的Value；Map字符串无效或Key不存在时返回false。 |
| mapRemove(map, key)     | 删除已有Key。         | string，Map；Map字符串无效时返回false。             |
| mapContains(map, key)   | 检查Map是否包含给定Key。  | bool；Map字符串无效时也返回false。                  |

附录A中的声明文件还提供了可由上述原子函数组合而成的函数。

| 函数定义                   | 函数说明           | 返回值说明                                       |
|------------------------|----------------|---------------------------------------------|
| arrayHas(array, index) | 检查数组中是否包含给定下标。 | bool；数组字符串无效或者不包含时返回false。                  |
| isArrayEmpty(array)    | 检查给定数组是否为空。    | bool；数组为空时返回true，数组字符串无效或者数组不为空时返回false。    |
| arrayFirst(array)      | 获取给定数组中第一个元素。  | 给定元素值；数组字符串无效或者数组为空时返回false。                |
| arrayLast(array)       | 获取给定数组中最后一个元素。 | 给定元素值；数组字符串无效或者数组为空时返回false。                |
| isMapEmpty(map)        | 检查给定Map是否为空。   | bool；Map为空时返回true，Map字符串无效或者Map不为空时返回false。 |

提示：由于Ink语言没有异常处理功能，数组/Map无效也只能返回false。
