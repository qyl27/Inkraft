# 剧情脚本编写

其他语言: [英语](../en/Writing-Story-Scripts.md)

Ink脚本的语法请参阅 [官方教程](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md)。

本文档的剩余内容可能会用到Ink脚本语言的相关前置知识。

Ink脚本语言本身支持的数据类型有：Bool、Int32、Float32、String，List，其中：
- Bool的取值是true和false；
- 如果数值超过Int32和Float32的范围，Ink会静默忽略超出长度的部分，而只保留低位数据；
- 不同的数据类型可以自动向上隐式转换；
- Float32的取值不包括IEEE754标准中定义的特殊值+Infinity、-Infinity、sNaN、qNaN、+0.0、-0.0，
  - ±Infinity会被转换成±3.4E38F，
  - sNaN、qNaN、+0.0、-0.0都会被转换成+0.0；
- 没有表示Null或者异常的类型；
- List表示只能在若干有限取值中选取其中一个，事实上是一种枚举类型（Enum）。




## 样式代码

剧情脚本支持使用[MiniMessage](https://docs.advntr.dev/minimessage/format.html)设置文本的样式。MiniMessage的标准标签均可使用，包括颜色、装饰、悬浮提示、点击事件、渐变等。



## 引擎函数

本节介绍的是Inkraft所提供的引擎函数。

在Ink脚本中，可以使用`EXTERNAL <函数定义>`声明由Inkraft提供的基础外部函数。附录A的include文件既包含这些external声明，也包含由基础函数组合实现的Ink便捷函数。引擎函数分为系统函数和游戏函数，前者和Ink脚本运行有关，后者用于操作Minecraft游戏内容。

编写脚本时建议直接使用`INCLUDE engine_functions_include.ink`引入附录A的文件。仅自行声明external无法获得其中以Ink实现的便捷函数。

在Inkraft引擎中，函数名一般使用camelCase。

函数参数的“可空”指可以用空字符串`""`来占位，因为Ink语言不支持函数重载，也没有表示空的数据类型故以此权宜。

#### 多并行流控制

**这是一个Ink语言的Beta功能。**

参见：[官方文档](https://github.com/inkle/ink/blob/master/Documentation/RunningYourInk.md#multiple-parallel-flows-beta)

并行流（Flow）是在同一个剧情脚本中保存多个不同的上下文状态的功能，全局变量、访问计数会在流之间共享，而当前指针、调用栈等会被流隔离。并行流可以用于实现剧情脚本级别的存档/读档或者可中断的对话等功能。

Flow以name作为索引，默认流的名称为`DEFAULT_FLOW`，它随着剧情脚本开始播放而创建，无法被删除，在脚本中可以视为始终存在。

修改Flow状态的`flowTo`、`newFlow`和`removeFlow`是向引擎发送切换并行流的请求，请求是一个队列，会在当前剧情行处理完成后执行。它们的返回值仅表示请求是否已被引擎接受，不表示最终是否执行成功。`isInFlow`和`hasFlow`只查询已提交的Flow状态，不包含等待执行的请求。

| 函数定义                | 函数说明                                                           | 参数说明                         | 返回值说明                                                  |
|---------------------|--------------------------------------------------------------------|------------------------------|-------------------------------------------------------------|
| isInFlow(name)      | 检测玩家当前是否在指定流中。                                       | name：并行流名称。                  | bool，true代表是。                                          |
| hasFlow(name)       | 检测当前脚本状态中是否存在指定流。默认流总是存在。                 | name：并行流名称。                  | bool，true代表存在。                                        |
| isFlowEnded(name)   | 检测指定流是否已经结束，即没有后续剧情行或者选项。                 | name：并行流名称。                  | bool，true代表已结束。指定的流不存在也视为已结束。          |
| flowTo(name)        | 请求切换到指定流，目标在执行时必须存在。                           | name：并行流名称。                  | bool，true代表引擎已接受该请求，false代表当前无法接受请求。 |
| newFlow(name, knot) | 请求从指定的故事结（Knot）创建流并切换到其中，若目标已存在则覆盖。 | name：并行流名称。<br />knot：Knot名。 | bool，true代表引擎已接受该请求，false代表当前无法接受请求。 |
| removeFlow(name)    | 请求删除指定非默认流。若删除当前流，删除后会切换回默认流。         | name：并行流名称。                  | bool，true代表引擎已接受该请求，false代表当前无法接受请求。 |

附录A中的声明文件还提供了用于处理默认流的常用函数。

| 函数定义              | 函数说明              | 返回值说明          |
|-------------------|-------------------|----------------|
| isInDefaultFlow() | 检测玩家当前是否在默认Flow中。 | bool，true代表是。  |
| flowToDefault()   | 请求切换到默认Flow。      | bool，true代表引擎已接受该请求。 |

#### 引擎变量函数

引擎变量附加于玩家，用于把数据持久化，或者在不同脚本之间传递。

变量名推荐使用snake_case，最好在最前面冠上数据包的命名空间Id以避免和其他数据包冲突。

如需在玩家间共享的变量，建议通过游戏函数运行服务器命令，辅以原版的计分板或命令存储Storage机制实现。

引擎变量会存储Bool、Int32、Float32和String的类型。Array和Map本身以String表示。

由于Ink语言的List类型是和所运行的脚本绑定的枚举值，离开特定脚本以后没有意义，引擎会自动把List类型的变量值解析为String类型保存，以String类型读取。

| 函数定义                     | 函数说明             | 参数说明                      | 返回值说明                               |
|--------------------------|------------------|---------------------------|-------------------------------------|
| hasVariable(name)        | 检查引擎变量是否存在于玩家身上。 | name：变量名。                 | bool，true代表存在，false代表不存在。           |
| getVariable(name)        | 获取引擎变量值。         | name：变量名。                 | any，对应类型的引擎变量值。<br />变量不存在时返回false。 |
| setVariable(name, value) | 设置引擎变量值。         | name：变量名。<br />value：变量值。 | bool，true代表成功。                      |
| unsetVariable(name)      | 擦除引擎变量。          | name：变量名。                 |                                     |
| clearVariables()         | 清空全部引擎变量。        |                           |                                     |

### 函数参数字符串转义

函数的字符串参数中的特殊字符需要转义，Ink语言也使用`\`转义。
需要转义的字符有：`"`、`{`、`}`、`\`、`|`、`#`；而单独的`<`和`>`不需要转义，只有在组成`<>`、`->`和`<-`等有Ink语法含义的序列时才需要转义成`\<\>`、`\-\>`和`\<\-`。

例如，函数参数中需要传入一个NBT字符串时，可以写作：

```ink
~ giveItem("minecraft:diamond", 1, "components", "\{\"minecraft:custom_name\":'\{\"text\":\"金钻石\"\}'\}")
```
